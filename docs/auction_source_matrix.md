\## 1. Purpose



This document defines the evidence hierarchy and field-level source rules for historical IPL auction ingestion.



It is a data-contract document.



It does not implement ingestion logic and does not define model features.



\---



\## 2. Source Hierarchy



\### Tier 1 — Primary authority



Official IPL/BCCI publications are authoritative wherever they provide the required field.



Examples:



\- official auction announcements

\- official auction lists

\- official auction result announcements

\- official retention announcements

\- official player-registration documents

\- official auction PDFs

\- official player regulations



\### Tier 2 — Reputable cross-check



Established cricket reporting may be used to independently verify:



\- sold/unsold outcome

\- winning franchise

\- final auction price

\- auction sequence

\- recalled/accelerated-round outcomes

\- details missing from an official source



\### Tier 3 — Discovery only



The following may assist with finding missing records but cannot independently establish a high-confidence raw record:



\- Wikipedia

\- Kaggle

\- fan-maintained databases

\- blogs

\- social media posts

\- search-engine snippets

\## 3. Field-Level Source Matrix



| Field | Primary evidence | Cross-check | NULL allowed | Rule |

|---|---|---|---|---|

| `id` | Generated by ingestion | None | No | Stable raw-row identifier |

| `auction\_year` | Official auction documentation | Secondary reporting | No | Auction-cycle year |

| `auction\_date` | Official auction announcement/result | Secondary reporting | Yes | Use exact date when established |

| `auction\_type` | Official IPL/BCCI documentation | Secondary reporting | No | Major/mini/mega/etc. as officially applicable |

| `player\_name\_raw` | Official auction list | Reputable secondary source | No | Preserve source spelling |

| `cricsheet\_player\_id` | Approved Cricsheet/provenance mapping | None | Yes | Do not infer |

| `entry\_mechanism` | Official IPL/BCCI documentation | Reputable reporting | No | `AUCTION`, `DRAFT`, or `UNKNOWN` |

| `sold\_status` | Official result where available | Reputable outcome list | No | Final known outcome |

| `retention\_status` | Official retention announcement | Reputable reporting | No | Separate from auction outcome |

| `franchise\_raw` | Official auction result/retention source | Reputable outcome list | Yes | NULL for confirmed unsold/unknown |

| `base\_price\_inr\_lakh` | Official auction list | Reputable reporting | Yes | Normalize to INR lakh |

| `base\_price\_display` | Official auction list | Reputable reporting | Yes | Preserve human-readable source value |

| `sold\_price\_inr\_lakh` | Official auction result | Reputable outcome list | Yes | Auction purchase price only |

| `sold\_price\_display` | Official auction result | Reputable outcome list | Yes | Preserve displayed auction price |

| `retention\_price\_inr\_lakh` | Official retention documentation | Reputable reporting | Yes | Separate from auction purchase price |

| `retention\_price\_display` | Official retention documentation | Reputable reporting | Yes | Preserve source representation |

| `retention\_price\_type` | Official regulations/retention documentation | Reputable reporting | Yes | `BCCI\_PURSE\_DEDUCTION`, `CONTRACTED\_SALARY`, or `UNKNOWN` |

| `currency` | Source documentation | None | No | Expected value is `INR` |

| `price\_note` | Source documentation + ingestion review | Cross-check source | Yes | Explain special price circumstances |

| `player\_category` | Official auction list | Reputable reporting | Yes | Preserve source category where available |

| `season\_franchise\_purse\_crore` | Official IPL/BCCI regulations | Reputable reporting | Yes | Auction-cycle purse context |

| `source\_primary` | Ingestion manifest | None | No | Primary source identifier |

| `source\_primary\_url` | Ingestion manifest | None | No | Exact primary source URL |

| `source\_crosscheck` | Ingestion manifest | None | Yes | Secondary source identifier |

| `source\_crosscheck\_url` | Ingestion manifest | None | Yes | Exact cross-check URL |

| `retrieval\_date` | Ingestion execution | None | No | Date evidence was retrieved |

| `data\_confidence` | Validation process | Source agreement | No | Confidence assigned after evidence review |

| `source\_conflict\_note` | Validation process | Conflicting source evidence | Yes | Required when material conflict exists |
